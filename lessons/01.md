# 01 · 类型、字符串与异常：把输入变成可信数据

第 1 周 · 首次讲解与小练习约 60 分钟，项目实践另计。

业务后端经常接收不完整或错误的输入。今天用工单标题理解静态类型、引用与边界校验，而不是背一遍语法表。

## 类型在什么时候约束你

int 保存整数值，boolean 保存真假，String 是引用类型。String title = 42 无法通过编译。var 只是让编译器推断局部变量类型，不会变成 Python 那样的动态绑定；var x = 1 后仍不能给 x 赋字符串。Long 等包装类型可以为 null；把 null 自动拆箱为 long 会在运行时出错。

## 字符串比较与空值

== 比较引用是否指向同一对象，字符串内容比较使用 equals。不要因为常量池让某次 == 恰好返回 true 就依赖它。先判 null 再调用方法；&& 从左到右短路，可以用来保护后面的操作。isBlank 能识别空字符串和纯空白，strip 去除两端空白，但不会改变原字符串。

## 异常表达失败

异常沿调用栈向上传播，直到被合适的 catch 处理。IllegalArgumentException 是运行时异常，适合本课的非法参数。不要捕获后返回一个假成功，也不要把所有异常都转换成同一句“系统错误”导致无法诊断。Java 还有受检异常，需要捕获或在方法上声明；先掌握遇到编译提示时怎样处理。

## 联系你的 Python 经验

Python 的 str.strip() 返回新字符串；Java 的 String.strip() 也是如此。Python 的 == 通常用于内容比较，不能原样迁移到 Java 引用类型。

## 代码拆解

```java
public static String normalizeTitle(String raw) {
    if (raw == null || raw.isBlank()) {
        throw new IllegalArgumentException("标题不能为空");
    }
    String title = raw.strip();
    if (title.length() > 100) {
        throw new IllegalArgumentException("标题不能超过100个UTF-16代码单元");
    }
    return title;
}
```

|| 也会短路：raw 为 null 时不会执行 isBlank。length() 统计 UTF-16 代码单元，部分 emoji 占两个；如果产品要求按用户可见字符计数，需要另行定义规则，不能把它简单称为“字数”。

## 自测

### 1. raw 为 null 时，哪个表达式可以安全判断为空？

1. raw.isBlank() || raw == null
2. raw == null || raw.isBlank()
3. raw.equals(null)

<details>
<summary>答案与原因</summary>

答案：2。短路求值在左边为 true 时跳过右边，从而不对 null 调用方法。

</details>

### 2. var x = 1; 后再写 x = "1"; 会怎样？

1. 自动变成 String
2. 编译失败
3. 只在运行时失败

<details>
<summary>答案与原因</summary>

答案：2。var 推断出的局部变量仍然是静态类型 int。

</details>
