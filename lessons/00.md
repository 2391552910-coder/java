# 00 · 先跑起来：JDK、编译与第一个程序

第 准备 周 · 首次讲解与小练习约 45 分钟，项目实践另计。

今天只完成一件事：在自己的电脑运行 Java，并能解释源文件、编译器和 JVM 各做什么。你已有 Python 基础，不需要重新学习循环的概念。

## 三个角色

JDK 是开发工具包，包含 javac 编译器、java 启动器及其他工具。javac 把 .java 源码编译为 .class 字节码；java 启动 JVM 执行字节码。编译期发现的类型错误与运行时异常是两类问题：前者让程序无法构建，后者在具体输入触发时才出现。

## 安装与检查

安装一个 JDK 21，使用发行商的正式安装程序，例如 Eclipse Temurin。编辑器可以用已有的 IntelliJ IDEA 或 VS Code。重新打开终端，运行 java -version 和 javac -version，两者均应存在且主版本一致。如果 java 有而 javac 没有，先检查是否安装的是 JDK，以及 PATH 指向了哪个目录；不要连续随机重装。

## 文件与入口

把下方代码保存为 Hello.java。public 类名必须与文件名对应。main 是本例入口；String[] args 是命令行参数数组。System.out.println 用来观察结果。先在终端跑通，再使用 IDE 的运行按钮，这样出错时能区分工具配置与代码问题。

## 联系你的 Python 经验

Python 常用 python hello.py 直接运行；这里先执行 javac Hello.java，再执行 java Hello。类名后的运行命令没有 .class 后缀。Java 也有源文件启动方式，本课先使用显式编译流程。

## 代码拆解

```java
public class Hello {
    public static void main(String[] args) {
        String topic = args.length > 0 ? args[0] : "Java";
        System.out.println("开始学习 " + topic);
    }
}
```

编译后执行 java Hello Agent，输出“开始学习 Agent”；不传参数时输出“开始学习 Java”。三元表达式只选择一个分支，避免直接读取不存在的 args[0]。

## 自测

### 1. javac 发现类型错误后，应该先做什么？

1. 继续执行旧的 .class 证明修改有效
2. 修复源码并重新编译
3. 修改数据库配置

<details>
<summary>答案与原因</summary>

答案：2。编译失败意味着没有生成本次修改对应的可执行字节码。旧产物可能仍存在。

</details>

### 2. 本例 javac Hello.java 成功后，运行命令是什么？

1. java Hello
2. java Hello.class
3. javac Hello.class

<details>
<summary>答案与原因</summary>

答案：1。java 的类启动方式接收类名；javac 是编译器。

</details>
