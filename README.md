# Java学习

面向 AI 应用 / Agent 开发的 12 周 Java 业务后端学习路线。

适合已有 Python、FastAPI、RAG、LangChain 基础，希望补充 Java 后端能力的学习者。建议每周 15–20 小时；时间减半时相应延长周期。这里是学习资料与练习计划，不是已经完成的应用代码。

## 开始学习

1. 阅读 [12 周路线与资源](docs/roadmap.md)，每阶段按“阅读 → 实现 → 验收”推进。
2. 按 [项目要求](docs/project.md) 逐步实现 AI 知识库与工单助手。
3. 每周更新 [学习进度](PROGRESS.md)，记录代码、测试结果和问题。

## 总体安排

| 周次 | 重点 | 交付 |
|---|---|---|
| 1–2 | Java 语言、面向对象、集合、异常 | 命令行工单程序 |
| 3 | Maven、JUnit、调试、Git | 可构建、可测试的项目 |
| 4–5 | Spring Boot、HTTP、分层、参数校验 | 工单与知识库 REST API |
| 6–7 | SQL、MyBatis、索引、事务 | 数据持久化、回滚和并发控制 |
| 8 | Spring Security、数据权限、Redis | 权限隔离与缓存 |
| 9–10 | Java 与 Python AI 服务协作 | 超时、幂等、任务状态、流式响应 |
| 11 | 并发与 JVM | 有界任务执行与故障排查记录 |
| 12 | Docker、集成测试、部署 | 可复现部署和演示 |

## 学习原则

- Python 保留 AI 主流程；Java 负责业务、权限与事务。不为了练语言重写所有 AI 代码。
- 一套主教程配合官方文档与项目，不同时刷多套课程。
- SQL 手写起步；先理解事务与权限，再学习复杂框架。
- 暂缓 Spring Cloud 全家桶、Kubernetes、分库分表及复杂多 Agent 架构。
- 依赖版本以实际选定的稳定 Spring Boot 版本兼容要求为准；不要混用不同主版本教程，不使用预览或 SNAPSHOT 依赖起步。
- 学习项目不需要花费购买云服务；先本地运行，模型可用模拟接口替代。
