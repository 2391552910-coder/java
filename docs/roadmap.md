## 每课循环

1. 用 10–20 分钟读讲解；先预测代码行为，再运行。
2. 用 20–40 分钟自己实现一个小任务，留下最小失败案例。
3. 卡住才依次展开提示，不立即抄参考思路。
4. 回答自测；错题回到相关段落解释原因。
5. 在终端或 IDE 验证实践标准，记录证据。
6. 次日或三天后脱离 AI 完成一个变式。

一次课不要求完成整周项目。框架整合、数据库实验和最终部署通常需要额外多次实践。

## 第一周建议

- 第一天：00，跑通编译；01，写标题校验。
- 第二天：不看答案复写标题校验；02，工单状态。
- 第三天：03，内存仓库。
- 第四天：运行 [练习检查器](../exercises/core/README.md)，修复失败。
- 第五天：完成 [阶段挑战 A](checkpoints.md)，根据错误决定是否继续。

后续按每周可用时间推进，不以看完页面代替掌握。
