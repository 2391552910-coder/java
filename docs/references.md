# 可选参考与技术核对来源

日常学习看本仓库 lessons 即可。以下只用于查版本、确认行为或深入扩展，**不是必读作业**。

| 内容 | 来源 | 本课程如何使用 |
|---|---|---|
| Java 语言与 JVM | [Dev.java](https://dev.java/learn/) | 类型、集合与工具概念 |
| JDK 安装 | [Eclipse Temurin](https://adoptium.net/temurin/releases/) | 选择 JDK 21 正式版本 |
| Maven | [Maven 入门](https://maven.apache.org/guides/getting-started/) | 构建目录与生命周期 |
| JUnit | [JUnit](https://docs.junit.org/current/user-guide/) | 后续迁移为测试框架 |
| Spring | [Spring Guides](https://spring.io/guides/) · [Initializr](https://start.spring.io/) | 创建 Spring 工程 |
| MyBatis | [中文文档](https://mybatis.org/mybatis-3/zh_CN/index.html) | SQL 参数绑定 |
| 事务 | [Spring 事务注解](https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/annotations.html) | 自调用与代理边界 |
| 校验 | [Spring MVC Validation](https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-controller/ann-validation.html) | DTO 校验入口 |
| 权限 | [Spring Security](https://docs.spring.io/spring-security/reference/servlet/authorization/authorize-http-requests.html) | URL 与资源级授权 |
| HTTP | [HttpRequest.Builder](https://docs.oracle.com/en/java/javase/21/docs/api/java.net.http/java/net/http/HttpRequest.Builder.html) | 请求超时行为 |
| Redis | [Redis](https://redis.io/docs/latest/) | 缓存命令与类型 |
| 部署 | [Docker Compose](https://docs.docker.com/compose/) | 网络与服务配置 |

核对日期：2026-10-19。讲解为本课程整理，外部链接可能更新。框架示例注明了片段边界，不承诺脱离依赖、import 和工程配置即可运行。
