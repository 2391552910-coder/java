# 互动学习页使用说明

## 打开

下载仓库（GitHub 绿色 Code 按钮 → Download ZIP），解压后双击本目录 **index.html**。页面不依赖网络、CDN 或外部字体，不需要 API Key，也不调用模型。

若本地文件模式无法保存进度，可以在仓库根目录执行 `node tools/serve.cjs`，然后打开 http://localhost:8765。访问地址改变时，本地存储也会改变；先导出再导入即可迁移。

GitHub 的文件预览不会执行 HTML，直接打开仓库中的 index.html 链接看不到互动效果。当前没有替你开启 GitHub Pages 或创建额外网站。

## 互动内容

- 16 课中文正文，包含 Python 对照、代码说明、任务与三级提示。
- 32 道概念自测，提交后展示原因，错误答案进入错题复习。
- 三项实践验收自评；全部勾选后记为课程实践完成。
- 每课独立笔记与可复制的 AI 导师/代码审查提问。
- 独立练习记录与日期复习标记；错题建议次日，独立练习建议 3 天后复习。
- JSON 导出/导入，迁移笔记、答案与进度；导入前校验格式。

复习标记只会在打开页面时显示，不会发通知，也不是已创建的定时任务。浏览器存储失败会提示，建议定期导出。进度不会自动写回 GitHub。

## 编程与 AI 问答的边界

页面只自动判概念题，不编译 Java，不执行 SQL，不把“写了笔记”当成编程正确。代码要在自己的 IDE/终端运行。参考代码标注了独立程序、片段与伪代码的区别。

“复制导师提问”会把当前任务、验收与笔记整理成上下文，粘贴到 AI 聊天后才开始真正的问答。本地页没有内置聊天机器人，不应输入模型密钥。

## 修改内容

课程源在 `course.js`。更新后在仓库根目录执行 `node tools/build-lessons.cjs`，同步生成 `lessons/*.md`。应用进度逻辑在 `model.js`，检查命令为 `node --test tests/*.test.cjs`。
